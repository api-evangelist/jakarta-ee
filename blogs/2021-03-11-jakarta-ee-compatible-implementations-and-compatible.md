Jakarta EE is a set of open specifications used for enterprise Java application development. It is a continuation of Java EE technology that gathers the wide community of Java developers interested in advancing the specifications for future cloud native Java enterprise applications. Each specification release includes its respective Technology Compatibility Kit (TCK).
